# Jac Creation — Architecture Studio Website

A responsive architecture studio website built with **React and Vite** for the Jac Creation practical assignment.

The website is designed with a **minimal, premium, and editorial aesthetic**, using architectural photography, refined typography, neutral tones, generous spacing, and a responsive layout across desktop, tablet, and mobile devices.

## Features

- Responsive architecture studio homepage
- Premium editorial design
- Desktop, tablet, and mobile responsive layout
- Mobile hamburger navigation
- Smooth navigation between sections
- Full-screen hero section
- About Us / Philosophy section
- Design Framework section
- Selected Work section
- Featured project showcase
- Gallery section
- Contact call-to-action
- Responsive footer

## Sections

- Home
- About Us
- Projects
- Gallery
- Contact Us

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/SumitMali2003/Jac-Creation.git
```

### 2. Navigate to the project folder

```bash
cd Jac-Creation
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open this URL in your browser:

```text
http://localhost:5173
```

## Available Commands

### Start Development Server


## Design Approach

The website follows a quiet and refined architectural visual language.

The design focuses on:

- Minimal interface
- Editorial typography
- Neutral cream and charcoal color palette
- Large architectural imagery
- Generous whitespace
- Subtle gold accents
- Clear visual hierarchy
- Responsive layouts
- Simple and focused navigation

The design intentionally avoids excessive animations, loud colors, heavy shadows, and crowded layouts.

## Responsive Design

The website is optimized for:

- Desktop
- Laptop
- Tablet
- Mobile

On smaller screens, the navigation changes to a hamburger menu and the project, gallery, CTA, and footer sections adapt to the available screen size.
